Return a map instead of only the answer text. The map has these keys:
text
The answer text.
thinking
The model's thinking, if it reported any.
toolCalls
A list of maps with the id, name and JSON arguments of each tool call.
finishReason
Why the model stopped, or null.
usage
A map of inputTokens, outputTokens and cachedTokens, or null if the model did not report usage.
model
The id of the model that answered.
conversationId
The id of the conversation recorded on the build.
