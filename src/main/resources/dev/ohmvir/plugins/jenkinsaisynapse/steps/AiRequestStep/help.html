Sends a request to an AI model, running any tools it calls, and returns its answer. Set prompt, promptId, or both: the prompt text is added to the base prompt. The request's progress is written to the build log as it happens, and the conversation is kept with the build under AI Conversations.

Aborting the build cancels the request. The request also fails if it takes longer than the step's timeout or the timeout configured for the model's client, whichever is shorter. 

def answer = aiRequest 'Summarize the changes in this build'

def review = aiRequest(promptId: 'code-review', prompt: diff,
                       model: 'anthropic:claude-opus-5-5',
                       skills: ['java-style'],
                       returnDetails: true)
echo review.text
echo "Used ${review.usage?.outputTokens} output tokens"

tools and skills are lists of tool and skill names. Tools are provided by other plugins, and skills also make the built-in read_skill_file tool available. They are not shown in the snippet generator, and neither are these lists:

files
Workspace files to attach to the request. PNG, JPEG, GIF and WebP images, audio and video are sent as such, anything else (including SVG and BMP images) as a file. Each may be up to 32 MB. Needs a workspace, so use it inside a node block.
outputTypes
The outputs the response must contain, out of text, image, audio, video and file. Only models that can produce all of them are used. Defaults to ['text'].
stopSequences
Text that makes the model stop generating when it produces it.
node {
    def result = aiRequest(prompt: 'Draw a diagram of this design', files: ['design.md'],
                           outputTypes: ['text', 'image'], outputDir: 'ai-output', returnDetails: true)
    archiveArtifacts artifacts: 'ai-output/*'
}
