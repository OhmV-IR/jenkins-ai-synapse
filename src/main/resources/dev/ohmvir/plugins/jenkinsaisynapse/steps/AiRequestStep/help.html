Sends a request to an AI model, running any tools it calls, and returns its answer. Set prompt, promptId, or both: the prompt text is added to the base prompt. The request's progress is written to the build log as it happens, and the conversation is kept with the build under AI Conversations.

Aborting the build cancels the request. The request also fails if it takes longer than the timeout configured for the model's client. 

def answer = aiRequest 'Summarize the changes in this build'

def review = aiRequest(promptId: 'code-review', prompt: diff,
                       model: 'anthropic:claude-opus-5-5',
                       tools: ['readFile'], skills: ['java-style'],
                       returnDetails: true)
echo review.text
echo "Used ${review.usage?.outputTokens} output tokens"

tools and skills are lists of tool and skill names. They are not shown in the snippet generator.
