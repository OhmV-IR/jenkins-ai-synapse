A workspace directory to save the images, audio, video and files the model produces to. They are named after the file name the model gave them, or image-1.png and so on. A name without an extension, such as the id a provider gives a file, gets the extension for its content type, for example .pdf, or .bin when the content type is not a known one. Needs a workspace, so use it inside a node block. With returnDetails, the files entry lists what was saved.
