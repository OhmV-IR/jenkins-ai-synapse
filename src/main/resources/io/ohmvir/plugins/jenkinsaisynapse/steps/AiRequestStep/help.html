Sends a request to one of the AI models configured under Manage Jenkins » Models and returns its answer. While the model works, its answer and the tools it calls are printed to the build log, and aborting the build cancels the request.

The simplest form takes the prompt and returns the answer as a string:

def summary = aiRequest 'Summarize the release notes in three bullet points'

Every other parameter is optional:

def review = aiRequest(
    prompt: 'Review this change and list any bugs you find',
    model: 'anthropic:claude-sonnet',     // omit to use the first model that supports the request
    systemPrompt: 'You are a strict code reviewer',
    files: ['build/changes.diff'],        // workspace files to attach (text, documents, images, audio, video)
    tools: ['readFile'],                  // tools the model may call
    skills: ['code-review'],              // skills to give the model
    temperature: 0.2,
    maxOutputTokens: 4000,
    thinkingLevel: 'high',
    timeout: 300,                         // seconds for the whole request
    returnResponse: true                  // return a map instead of the answer only
)
echo review.text
echo "Used ${review.usage?.outputTokens} output tokens"

Also available: topP, topK, stopSequences (a list of strings), outputTypes (outputs the response must contain, from text, image, audio, video and file), outputDir to save produced files, conversationId to continue a conversation across builds, maxTurns, expandEnvVars, and quiet or verbose to control what is printed to the build log.

Start from a prompt stored under Manage Jenkins » Base Prompts with promptId; a prompt given alongside it is appended, and settings given to the step override the stored ones.

With returnResponse: true the step returns a map with these keys:

text
The model's final answer: the text it produced after its last tool call.
allText
All the text the model produced, including text before tool calls.
thinking
The model's thinking, if it produced any.
model
The id of the model that answered.
steps
How many times the model was called.
finishReason
STOP, TOKEN_CAP, SAFEGUARD or TOOL_CALLS, if the client reports it.
usage
A map of inputTokens, outputTokens and cachedTokens, if the client reports it.
toolCalls
A list of maps of id, name, arguments, successful and result.
citations
A list of maps describing the citations in the answer.
files
A list of maps of name, kind, contentType, size and, with outputDir, path for each image, audio, video or file the model produced.
conversationId
The UUID of the conversation, with conversationId.
